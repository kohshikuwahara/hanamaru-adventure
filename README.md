# 🐶 はなまるの冒険

## 1. 制作アプリの概要

飼い犬のコーギー「はなまる」が最強の猟犬を目指し、イノシシ・鹿・クマなどの動物と戦いながら肉を集めるブラウザゲームです。

G's ACADEMYのJavaScript課題として制作しました。

**🎮 ゲームはこちら**

https://kohshikuwahara.github.io/hanamaru-adventure/

## 2. ゲームの遊び方

- 5種類の技から好きな技を選択して敵と戦います。
- 技には相性があり、勝敗によってHPが減少します。
- 敵を倒すと肉を1個獲得できます。
- 肉を5個集めるとゲームクリアです。
- はなまるのHPが0になるとゲームオーバーです。

## 3. 工夫した点・改善した機能

### ① 戦闘システム
- イノシシ・野良犬・野良猫・鹿・クマの5種類の敵を実装
- 敵ごとにHPと攻撃力を設定
- 各敵に3種類の技を設定し、ランダムに表示
- 技の相性によって勝敗を判定

### ② 戦闘画面の改善
- はなまると敵のHPゲージを追加
- それぞれの画像の下に技名を表示
- 攻撃時にキャラクターが動くアニメーションを追加
- ダメージを受けると画像が震える演出を追加

### ③ 肉の獲得演出
- 敵を倒すと肉を1個獲得
- 獲得数に合わせて🥩アイコンが増える仕組みを実装
- 「🥩 GET！」のアニメーションを追加

### ④ ゲーム終了・リスタート
- 肉5個獲得でゲームクリア画面を表示
- HPが0になるとゲームオーバー画面を表示
- どちらもリスタートできる機能を実装

### ⑤ 音・デザイン
- BGMのループ再生
- 攻撃時の効果音
- PC・スマートフォンに対応したレイアウト

## 4. 使用技術

- HTML：画面構成
- CSS：デザイン・アニメーション・レスポンシブ対応
- JavaScript：戦闘処理・勝敗判定・ゲーム進行
- jQuery：DOM操作・イベント処理
- Git / GitHub：バージョン管理
- GitHub Pages：ゲームの公開

## 5. 制作を通じて学んだこと

JavaScriptの変数・配列・関数・条件分岐を、実際のゲーム制作を通じて学びました。

特に、HPの数値とゲージを連動させる処理や、イベントをきっかけにアニメーション・効果音を実行する処理が勉強になりました。
